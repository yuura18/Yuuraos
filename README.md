# Yuura OS

Antarmuka CLI GodMode dengan telemetri sistem ringan di Ubuntu root (Termux proot-distro).

## Cara Install (Pengguna Baru)
1. Masuk ke Ubuntu di Termux:
   proot-distro login ubuntu

2. Clone repositori dan jalankan installer:
   git clone https://github.com/yuura/yuuraos.git
   cd yuuraos
   chmod +x install.sh
   ./install.sh
